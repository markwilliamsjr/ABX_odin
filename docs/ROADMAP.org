#+title: ABX! Roadmap

* ABX! Roadmap

Remaining work only, ordered by dependency within each phase. A phase starts
when the one before it is verified.

- Why a design is the way it is: [[file:DECISIONS.md][DECISIONS.md]]
- Intended design: [[file:ARCHITECTURE.md][ARCHITECTURE.md]]
- What exists today: [[file:PROJECT.md][PROJECT.md]]
- Current working context: [[file:SESSION.md][SESSION.md]]

** Before starting: open decisions

Decide each before writing the code that depends on it.

- [ ] **Does the flee threshold scale with buff count?** Blocks 1.3.
- [ ] **Frenzied stacking** — additive-with-cap or free multiplication? Blocks
      buff tuning, not implementation.
- [ ] **Boss shape, roster entry, meter interaction** — deferred with Phase 8,
      but decide before tuning difficulty.
- [ ] **Settings precedence and runtime vsync fallback** — blocks Phase 5.

** Phase 1 — Level and wave lifecycle (current)

Finish level advancement and transition, plus the minimum needed to observe it.

*** 1.1 Settle range semantics

Inclusive ranges were chosen on 2026-10-31: the documented ranges stand, and
~hi + 1~ moves into the draw sites. See
[[file:DECISIONS.md::Range semantics][Range semantics]].

- [X] Decide inclusive ~rand.int_range~ with ~hi + 1~ at every draw site.
- [X] Apply the ~+1~ to ~wave_count_picker~, the count jitter, and
      ~threshold_picker~; clamp ~MAX_WAVES~ before the ~+1~.
- [X] Confirm the documented wave-count ranges match the decision.

*** 1.2 Wave membership and resolution

Ownership, counters, crossing detection, and advancement. The flee response is
1.3. Full detail: [[file:DECISIONS.md::Wave resolution and membership][Wave resolution and membership]].

- [ ] Move the ~Bacteria~ pool into ~Level~; store the index on ~Wave~ and the
      owning wave index on ~BacteriaCold~; clear ownership when it leaves play.
- [ ] Replace the formation, diver-count, and diver-selection scans with owner
      scans; delete ~enemy_indices~.
- [ ] Add ~destroyed_count~ and ~fled_count~ to ~Wave~; derive ~resolved~ as
      their sum.
- [ ] Reset counters, timers, flags, and level state in ~wave_init~ and
      ~level_init~, including the pool's zero-then-sentinel pass.
- [ ] Attribute deaths to the owning wave at health zero.
- [ ] Do not count a failed spawn; retry it, and guard the formation-shortfall
      case.
- [ ] Once spawning completes, apply
      ~destroyed_count * 1000 >= spawn_count * threshold_permille~ and set
      ~threshold_crossed~ once.
- [ ] Resolve dead, fled, and still-alive explicitly; complete the wave when
      ~resolved == spawn_count~.
- [ ] Advance ~wave_index~ once per completed wave; set ~Level.level_end~ when
      it reaches the level's wave count.
- [ ] Add temporary wave logs: init, crossing, resolution, advancement, level
      end.

*** 1.3 Fleeing and returning

- [ ] Flee the remaining bacteria when the fraction destroyed crosses the rolled
      threshold; resolve the wave at that moment.
- [ ] Move fled bacteria into a pending roster on ~World~, not ~Level~.
- [ ] Queue each fled bacterium for the next wave, positionally.
- [ ] Let carried bacteria flee again: fresh buff roll, fresh health restore, no
      escape counter.
- [ ] On return, roll a resistance buff and restore health to spawn max.
- [ ] Bound the roster against ~MAX_ENEMIES~; drop the oldest when full.
- [ ] Add a fleeing-prohibited flag to ~Level~ and skip the threshold roll when
      it is set.

*** 1.4 Resistance buffs

- [ ] Add a ~BuffCategory~ enum: ~Hardy~, ~Resistant~, ~Biofilm~, ~Frenzied~.
- [ ] Hold buffs per instance on ~BacteriaCold~ as a fixed 5-slot array of
      ~(category, magnitude)~ pairs.
- [ ] Add a separate ~BUFF_DEFS~ table with absolute magnitudes.
- [ ] Roll the category from the full set on each return; repeats allowed.
- [ ] Wire ~species_unlocked~ into spawning so ~bacteria_spawn~ stops hardcoding
      ~.Strep~.

*** 1.5 Level transition

- [ ] Implement ~Level_Transition~ as a real state: hold the frame, show the
      level number, advance.
- [ ] Make it the single owner of level progression: derive the next seed, draw
      the wave count, initialize the waves, reset per-level state.
- [ ] Confirm and remove ~Level.end_chance~.

*** 1.6 Verify the slice

- [ ] Verify no seed collision across levels.
- [ ] Seeded replay: same seed, two runs, identical wave composition,
      formations, flee thresholds, and return schedules.
- [ ] Different seeds produce observably different runs from level 3 onward;
      levels 1–2 are deliberately near-identical.
- [ ] Level 1 is always one wave of five with a top-center entry across seeds.
- [ ] Wave-count ranges widen with level as documented.
- [ ] Flee and return do not perturb determinism.

*** 1.7 Unit tests

- [ ] Decide the seam: drive ~level_init~ end to end, or extract the budget
      split and jitter into a pure helper first.
- [ ] Cover ~derive_seed~, ~wave_count_picker~, ~threshold_picker~, and the
      budget split and jitter properties.
- [ ] Cover ~level_init~ smoke: level 1 shape, sum/floor rules, same-seed
      replay, different seeds differing.
- [ ] Use a local RNG in every test; the test runner seeds the global generator
      randomly.

** Phase 2 — Determinism

Make decisions tick-driven and keep wall-clock time for motion only.

- [ ] Split ~delta_time~ into real elapsed time for motion and a fixed-increment
      tick counter for decisions.
- [ ] Convert ~formation_complete_time~ from ~sdl.GetTicks()~ to a tick count.
- [ ] Fix the always-true dive gate.
- [ ] Make ~formation_complete~ tick-driven rather than derived from continuous
      motion.
- [ ] Audit for further wall-clock reads feeding decisions.

** Phase 3 — Frame pacing

Vsync is the normal pacer; the limiter exists only for the no-vsync path.

- [ ] Replace ~--no-vsync~ with ~--vsync <true|false>~; ~Config.vsync~ defaults
      to ~true~.
- [ ] Add ~--fps <n>~, default ~60~, ~0~ = unlimited; reject negatives.
- [ ] Apply ~PRESENTVSYNC~ conditionally in ~initialize_sdl~.
- [ ] Add a deadline-accumulator limiter after ~RenderPresent~, reading
      ~config.fps~ live.
- [ ] Correct the help text.
- [ ] Verify: ~--vsync false~ at 60 fps, ~--fps 0~ unbounded, vsync on at monitor
      rate, ~--fps 144 --vsync false~ at 144.

** Phase 4 — Clay UI foundation

command.

- [ ] Add ~scripts/build-clay.sh~ to compile the header into
      ~src/clay-odin/linux/clay.a~.
- [ ] Add a ~Makefile~ that owns staleness and calls the script
      (~make run ARGS="--debug"~, ~make check~, ~make test~, ~make clay~,
      ~make clean~).
- [ ] Ignore ~build/~ and ~src/clay-odin/linux/clay.a~.
- [ ] Add ~src/ui.odin~: ~UI~ struct, ~ui_init~ / ~ui_shutdown~,
      ~measure_text~ via ~TTF_SizeUTF8~, and ~ui_render~ for ~.Rectangle~,
      ~.Text~, ~.ScissorStart/End~ and ~.Border~.
- [ ] Port the debug overlay, then the menu, then settings.
- [ ] Add the pending ~wave_index~ and ~enemy_count~ lines to the overlay.
