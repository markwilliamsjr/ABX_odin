** Before starting: open decisions

Decide each before writing the code that depends on it.

- [X] **Does the flee threshold scale with buff count?** Resolved: scale by the
      wave's highest buff count, +50 permille per buff, clamped. See
      [[file:DECISIONS.md::Flee threshold scaling][Flee threshold scaling]].
- [ ] **Frenzied stacking** — additive-with-cap or free multiplication? Blocks
      buff tuning, not implementation.
- [ ] **Boss shape, roster entry, meter interaction** — deferred with Phase 8,
      but decide before tuning difficulty.
- [ ] **Settings precedence and runtime vsync fallback** — blocks Phase 5.

** Phase 1 — Level and wave lifecycle (current)

Finish level advancement and transition, plus the minimum needed to observe it.

*** 1.1 Settle range semantics

Inclusive ranges were chosen on 2026-10-31: the documented ranges stand, and
~hi + 1~ moves into the draw sites. See
[[file:DECISIONS.md::Range semantics][Range semantics]].

- [X] Decide inclusive ~rand.int_range~ with ~hi + 1~ at every draw site.
- [X] Apply the ~+1~ to ~wave_count_picker~, the count jitter, and
      ~threshold_picker~; clamp ~MAX_WAVES~ before the ~+1~.
- [X] Confirm the documented wave-count ranges match the decision.

*** 1.2 Wave membership and resolution

Ownership, counters, crossing detection, and advancement. The flee response is
1.3. Full detail: [[file:DECISIONS.md::Wave resolution and membership][Wave resolution and membership]].

- [X] Move the ~Bacteria~ pool into ~Level~; store the index on ~Wave~ and the
      owning wave index on ~BacteriaCold~; clear ownership when it leaves play.
- [X] Replace the formation, diver-count, and diver-selection scans with owner
      scans; delete ~enemy_indices~.
- [X] Add ~destroyed_count~ and ~fled_count~ to ~Wave~; derive ~resolved~ as
      their sum.
- [X] Reset counters, timers, flags, and level state in ~wave_init~ and
      ~level_init~, including the pool's zero-then-sentinel pass.
- [X] Attribute deaths to the owning wave at health zero.
- [X] Do not count a failed spawn; retry it, and guard the formation-shortfall
      case.
- [X] Once spawning completes, apply
      ~destroyed_count * 1000 >= spawn_count * threshold_permille~ and set
      ~threshold_crossed~ once.
- [X] Resolve dead, fled, and still-alive explicitly; complete the wave when
      ~resolved == spawn_count~.
- [X] Advance ~wave_index~ once per completed wave; set ~Level.level_end~ when
      it reaches the level's wave count.
- [X] Add temporary wave logs: init, crossing, resolution, advancement, level
      end.

*** 1.3 Fleeing and returning

Full detail: [[file:DECISIONS.md::Return queue mechanics][Return queue mechanics]],
[[file:DECISIONS.md::Flee animation phase][Flee animation phase]],
[[file:DECISIONS.md::Flee threshold scaling][Flee threshold scaling]],
[[file:DECISIONS.md::Resistance buffs][Resistance buffs]], and
[[file:DECISIONS.md::Buff storage representation][Buff storage representation]].

- [X] Add the buff scaffolding: ~BuffCategory~ (~Hardy~, ~Resistant~,
      ~Biofilm~, ~Frenzied~), a 5-slot array on ~BacteriaCold~, a separate
      ~BUFF_DEFS~ table, and ~max_health~.
- [ ] Add the ~.Buff~ seed category and store ~seed~ on ~Wave~.
- [ ] Add ~PendingBacteria~ and a FIFO roster on ~World~, capped at
      ~MAX_ENEMIES~; initialize it in ~world_init~ and never clear it in
      ~level_init~.
- [ ] Add ~Level.flee_prohibited~; skip the threshold draw and use ~1000~ when
      set.
- [ ] Apply ~clamp(base + 50 * max_buff_count, 500, 1000)~ at the crossing test.
- [ ] On crossing, start the zero-duration flee phase: mark remaining owned
      bacteria ~.Fleeing~, increment ~fled_count~, and ignore them in collision.
- [ ] Roll the buff at flee; replace the oldest when the 5 slots are full; store
      it on the roster entry.
- [ ] Queue each fled bacterium one wave ahead; decrement delays on wave
      completion; drop the oldest roster entry when full.
- [ ] On return, fill the next wave's existing spawn slots before fresh spawns;
      preserve species, apply buffs, and restore ~max_health~.
- [ ] Finish the flee phase: push to the roster, clear ownership, deactivate, and
      only then allow advancement.
- [ ] Let carried bacteria flee again: fresh buff roll, fresh health restore, no
      escape counter.
- [ ] Add flee, roster, buff, return, drop, and flee-prohibited logs.

*** 1.4 Resistance buff effects

- [ ] Apply ~Hardy~: raise max health from ~BUFF_DEFS~.
- [ ] Apply ~Resistant~: reduce damage taken; resolve its interaction with weapon
      weakness before tuning.
- [ ] Apply ~Biofilm~: absorb the first N hits.
- [ ] Apply ~Frenzied~: raise speed; keep the stacking question open until
      tuning.
- [ ] Wire ~species_unlocked~ into spawning so ~bacteria_spawn~ stops hardcoding
      ~.Strep~.

*** 1.5 Level transition

- [ ] Implement ~Level_Transition~ as a real state: hold the frame, show the
      level number, advance.
- [ ] Make it the single owner of level progression: derive the next seed, draw
      the wave count, initialize the waves, reset per-level state.
- [ ] Confirm and remove ~Level.end_chance~.

*** 1.6 Verify the slice

- [ ] Verify no seed collision across levels.
- [ ] Seeded replay: same seed, two runs, identical wave composition,
      formations, flee thresholds, and return schedules.
- [ ] Different seeds produce observably different runs from level 3 onward;
      levels 1–2 are deliberately near-identical.
- [ ] Level 1 is always one wave of five with a top-center entry across seeds.
- [ ] Wave-count ranges widen with level as documented.
- [ ] Flee and return do not perturb determinism.
- [ ] The roster survives a level transition and returns in the next level's
      first wave.
- [ ] The flee phase completes before the wave advances; collision ignores
      ~.Fleeing~ bacteria.
- [ ] A full roster drops its oldest entry; overflow returns stay queued rather
      than being lost.

*** 1.7 Unit tests

- [ ] Decide the seam: drive ~level_init~ end to end, or extract the budget
      split and jitter into a pure helper first.
- [ ] Cover ~derive_seed~, ~wave_count_picker~, ~threshold_picker~, and the
      budget split and jitter properties.
- [ ] Cover ~level_init~ smoke: level 1 shape, sum/floor rules, same-seed
      replay, different seeds differing.
- [ ] Cover effective threshold scaling, roster FIFO/capacity, and buff
      replacement.
- [ ] Use a local RNG in every test; the test runner seeds the global generator
      randomly.
